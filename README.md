# SignalGate

Screening aksi korporasi IDX dan laporan emiten dengan model Ollama lokal, validasi bukti, serta audit yang tersimpan di SQLite.

**[Panduan setup dan menjalankan aplikasi](docs/PANDUAN_SETUP.md)**

Backend: Python/FastAPI. Dashboard: React/TypeScript. Data baru berasal dari situs publik atau Sectors API; inferensi lokal tidak membutuhkan layanan LLM berbayar. Hasil merupakan screening, bukan instruksi transaksi.
